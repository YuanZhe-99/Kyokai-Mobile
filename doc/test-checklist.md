# 实机测试清单（0.1.3）

已在实机验证过的（启动、网络、连接与登录、桌面画面、键盘、触摸板、折叠屏笔记本模式、SSH、远程桌面、VNC）见 `doc/dev/progress.md`，这里只列还没在实机试过的。

装法：从 [Releases](https://github.com/YuanZhe-99/Kyokai-Mobile/releases) 下载 `Kyokai-Android-<版本>-arm64.apk`，或用 `tool/build_apk.sh` 构建；签名相同，可以直接覆盖安装。

出问题时：**设置 → 诊断 → 分享日志**；画面问题请同时打开"显示视频详情"并截图。每项后面写 ✅ / ❌ + 一句现象即可。

## 1. 画面与工具栏
- [ ] "画面贴顶"打开后，画面不满屏时贴在顶部
- [ ] 横屏收起的工具栏箭头可以拖动，松手贴边，重开 App 后位置不变
- [ ] 设置里调光标大小，预览和画面上的光标一致
- [ ] 反复进出桌面、切后台再回来，不再偶发无画面

## 2. 键盘（0.1.2）
- [ ] 按 Shift：数字键显示 `! @ #`，符号键显示 `? : "` 等
- [ ] Mac 主机：单按 Option 显示 `œ ∑ ™` 等；Option + Shift 换另一组；同时按 Cmd 时不显示
- [ ] 点键盘左上角的标签选 macOS / Windows / Linux / 自动，修饰键随之改变
- [ ] 同一台设备的 Kyokai、NanoKVM、远程桌面、VNC 分别记住自己的选择，重开 App 后仍在

## 3. 剪贴板
- [ ] 电脑上复制图片 → 手机里能粘贴；手机上复制图片 → 电脑上能粘贴
- [ ] 剪贴板历史（"会话"页的剪贴板图标、桌面菜单）列出两边复制过的内容，点一条可再次复制
- [ ] 电脑上复制一个文件 → 历史里出现文件名；点开后"保存"能存到选的位置，"分享"能发给其他应用（0.1.3）
- [ ] 复制一个含子文件夹的文件夹 → "分享"带上里面所有文件（0.1.3）
- [ ] 断开会话后，历史里的文件仍能保存和分享；重开 App 后不再有（0.1.3）

## 4. 远程桌面与服务
- [ ] 远程桌面连 Windows 10/11（服务器支持时会改用 H.264）：画面正确、颜色正常、移动窗口时不拖影、不晚一帧（0.1.3；App 里暂不显示用的是哪种编码，画面花了或黑屏请分享日志）
- [ ] 远程桌面旋转屏幕或展开折叠屏后，分辨率跟着变
- [ ] SSH → 文件：浏览、上传、下载（保存、分享）、重命名、删除、新建文件夹，传输进度和取消
- [ ] 导入带口令的密钥、ECDSA P-256 / P-384 密钥，用它登录 SSH

## 5. NanoKVM 与唤醒
- [ ] 主机有 NanoKVM 时，设备详情的 NanoKVM 按钮能看到连着的电脑，可以操作，不被"无权查看主机屏幕"挡住
- [ ] 设备列表和详情里的唤醒按钮、画面休眠时的唤醒按钮能点亮主机屏幕

## 6. 会话与 AI
- [ ] 同时打开两台桌面，桌面菜单里能切换；"会话"页列出桌面、AI、NanoKVM、SSH、远程桌面、VNC
- [ ] AI 任务历史：做过的任务在历史里，关掉 App 重开仍在，"清除"后没有（0.1.3）
- [ ] Activity 重建（如改系统深色模式、改字体大小）后不报错，会话还在

## 7. 设置
- [ ] 导航栏位置（底部 / 宽屏在侧边 / 总在侧边）、侧边栏左右
- [ ] 折叠屏展开时设置分左右两栏
- [ ] 网络：服务器一行一个输入框
- [ ] 关于：版本、Kyokai Core 版本、许可证

## 8. 其他
- [ ] TalkBack：图标按钮读出名称，画面读作"<设备名> 的屏幕"
- [ ] 诊断和视频详情显示首帧耗时
- [ ] 耗电：开一个桌面会话 30 分钟，记下电池统计里 Kyokai 的耗电
