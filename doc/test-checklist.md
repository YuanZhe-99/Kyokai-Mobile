# 实机测试清单（0.1.0 第 1 版）

装法：把 `build/app/outputs/flutter-apk/app-release.apk` 传到手机安装（只有 arm64）。签名是正式的 kyokai 证书，以后的版本可以直接覆盖安装。

出问题时：**设置 → 诊断 → 分享日志**，把文件发给我；画面问题请同时打开"显示视频详情"并截图。每项后面写 ✅ / ❌ + 一句现象即可。

## 1. 启动
- [ ] 打开后几秒内进入"设备"页，不停在"正在启动…"
- [ ] 设置 → 本机：显示 9 位设备 ID；**没有**"密钥仅在内存中"的警告
- [ ] 彻底关掉 App 再打开，设备 ID 不变

## 2. 网络
- [ ] 设置 → 网络 → 添加网络：填你电脑用的 EasyTier 服务器、网络名、密钥，保存
- [ ] 几秒内变为在线，显示地址和设备数
- [ ] "设备"页出现你的电脑，显示在线、路径（直连 / 局域网 / 中继）和延迟
- [ ] 不加网络，直接在搜索框输入电脑的局域网 IP 并连接，也能连上

## 3. 连接与登录
- [ ] 连接，输入密码，勾选"记住密码"后能看到桌面
- [ ] 断开再连，不再询问密码
- [ ] 故意输错密码：提示"密码错误"，可以重试
- [ ] 主机开启了确认时，手机显示"等待主机"，主机接受后进入

## 4. 画面
- [ ] 画面清晰、流畅；诊断叠层显示 hevc 或 h264 以及硬件解码器名
- [ ] 双指缩放、拖动平移，小地图位置正确
- [ ] 画质：切换"最快 / 平衡 / 最佳"、分辨率、帧率后画面恢复（不卡住黑屏）
- [ ] 多显示器的电脑：切换显示器
- [ ] 横屏：工具栏浮动，画面铺满
- [ ] 切到后台 1 分钟再回来，画面恢复（通知栏有会话通知）

## 5. 鼠标
- [ ] 触控板模式：单指移动光标、单击左键、双指单击右键、双指滚动、长按拖动
- [ ] 触摸模式：点哪里点哪里
- [ ] 设置里调指针速度有效果
- [ ] 外接鼠标（如有）：移动、左右键、滚轮

## 6. 键盘
- [ ] 打开屏幕键盘：字母、Shift、符号页、Fn 页都能输入
- [ ] Ctrl+C / Ctrl+V、Alt+Tab 在 Windows 上有效
- [ ] Mac 主机：显示 ⌃ ⌥ ⌘，⌘+空格能打开聚焦搜索
- [ ] "输入文字"发送一段中文，主机上正确出现
- [ ] 平板 / 横屏：分体键盘 + 中间触控板
- [ ] 外接键盘（如有）：普通键、方向键、组合键

## 7. 声音与剪贴板
- [ ] 打开声音，能听到主机的声音，延迟可接受
- [ ] 在主机复制文字 → 手机里能粘贴
- [ ] 在手机复制文字，回到 App 后 → 主机能粘贴

## 8. 会话操作
- [ ] 菜单：锁定主机、唤醒屏幕
- [ ] "会话"页列出打开的会话，可以回到会话或结束会话

## 9. AI 任务（主机启用了 AI 时）
- [ ] 下达一个简单任务，步骤逐条出现
- [ ] 需要批准的操作弹出批准 / 拒绝
- [ ] 暂停、继续、停止有效

## 10. 设置
- [ ] 主题浅色 / 深色 / 跟随系统；壁纸取色（Android 12+）
- [ ] 语言：简体中文、繁體中文、日本語、English 都能切换，没有显示成英文的漏项
- [ ] 登录密钥：新建密钥，分享公钥，主机接纳后不输密码直接登录
- [ ] 导出身份（设口令）→ 导入身份，设备 ID 不变
- [ ] "重新开始"后设备 ID 改变，且**之后**再关掉重开 App 仍没有"仅在内存中"警告（这是本次修复的问题）
