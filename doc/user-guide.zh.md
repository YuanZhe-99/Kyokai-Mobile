# Kyokai for Android 使用说明

## 第一次打开

Kyokai 启动内核，为这台手机分配 9 位设备 ID（设置 → 本机）。手机只做控制端，别人不能连进来。

## 连到你的电脑

- **网络**（设置 → 网络）：添加电脑所用的 EasyTier 网络：服务器（一行一个，回车加下一个）、网络名和密钥。最多 8 个，同时加入。
- **按地址**：在"设备"页的搜索框输入电脑的地址（局域网 IP、主机名）或设备 ID，点"连接"。

"设备"页列出连过的电脑，在线的在前；主机允许时显示 CPU、内存、磁盘。

## 电脑详情

点一台设备进入详情：

- **打开桌面**：它的屏幕。第一次要输入它的 Kyokai 密码（"记住"后不再询问）。
- **AI 任务**：它的 AI（有权限时）。时钟图标是连接期间它显示过的任务历史。
- **SSH、远程桌面、VNC**：经 Kyokai 隧道使用电脑自己的服务。SSH 里的 **文件** 用 SFTP 浏览：进入文件夹、上传、下载、重命名、删除。
- **NanoKVM**：电脑接了 NanoKVM USB 时，操作它连着的那台电脑。
- **唤醒屏幕**：重新打开它的显示器（设备列表上的太阳图标、休眠时画面上的按钮也可以）。
- **路径**：Kyokai 怎么到达它（自动、网络或某个地址）。
- **登录**：为它保存的登录信息，可以分别忘记。

## 桌面里

- **触控**：点按为单击，拖动为移动或选择，双指滚动，捏合缩放。设置 → 输入 选择触控或触摸板，以及光标大小。
- **键盘**：键盘按钮打开完整键盘（Ctrl、Alt、Win/Cmd、功能键、方向键）和触摸板；实体键盘和鼠标直接可用。
- **菜单**（⋮）：画质、声音、共享剪贴板、输入文字、剪贴板历史、切换到另一个打开的桌面、会话操作、断开。
- 横屏时工具栏收成一个箭头，可以拖到任意位置；点它展开工具栏。
- 折叠屏半折时进入笔记本布局。

## 剪贴板

桌面共享剪贴板时，手机上复制的文字和图片会发到电脑，电脑上复制的会来到手机。电脑上复制的文件会列出，但 Android 上不接收。"会话"页的剪贴板图标或桌面菜单里能看到历史，点一条可再次复制。

## 会话

"会话"页列出打开的一切：桌面、AI、NanoKVM、SSH、远程桌面、VNC。点一个回到它，× 结束。会话在后台保持（Android 显示通知）。

## 登录密钥

设置 → 登录密钥 可以新建或导入密钥，用于登录 SSH 和接受密钥的 Kyokai 主机：Ed25519、RSA（2048 位及以上）、ECDSA P-256 / P-384，OpenSSH 或 PEM 文件，有口令的会询问口令。私钥保存在 Kyokai 的加密存储里。

## 出问题时

设置 → 诊断 显示内核、视频和网络状态，可以分享日志。"显示视频详情"会在画面上叠加编码、解码器、帧率和首帧耗时。
